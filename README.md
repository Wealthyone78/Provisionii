# Provisionii public website release candidate

Website-only Next.js static export. No API, database, authentication, intake, uploads or internal operations are included. The existing private Workforce application remains separate.

`npm ci`, `npm run build` produces `out`. Vercel Git auto-deployment is disabled in configuration. Production release requires explicit founder approval of the exact artifact. This branch is a new, honestly identified website baseline descended from the existing remote main; it does not fabricate missing historical commits.
